# TeenSupport

Учебный проект: сайт анонимной психологической поддержки для подростков Казахстана (русский и казахский).

## Что внутри

- `index.html` — весь сайт (страницы, чат, запись к специалистам, быстрый выход).
- `netlify/functions/chat.mjs` — серверная функция для ИИ. Она обращается к модели Gemini через Netlify AI Gateway, поэтому никакой ключ не нужен и посетители ничего секретного не видят.
- `netlify.toml` — настройки для Netlify.

## Как работает ИИ

ИИ подключается через Netlify AI Gateway: Netlify сам передаёт функции доступ к модели, а расход списывается с кредитов аккаунта Netlify. Свой ключ Google создавать и добавлять не нужно. Модель можно поменять переменной `GEMINI_MODEL` (по умолчанию `gemini-3.5-flash`).

## Номера помощи

- 150 — телефон доверия для детей и молодёжи (бесплатно, круглосуточно)
- 111 — контакт-центр по вопросам семьи и защиты прав детей
- 112 — экстренные службы
